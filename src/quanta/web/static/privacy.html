PRIVACY, PLAINLY

Your code. Your decisions.

Quanta scans public Python repositories and lets you review supported changes before opening a draft pull request. It does not analyze private repositories.

GitHub sign-in

Quanta requests your GitHub profile and public repository access. GitHub's public_repo OAuth scope allows public repository writes; Quanta uses those permissions for the forks, branches and pull requests you request after reviewing a diff. Your GitHub token is encrypted in storage and is never sent to a scanner or exposed to browser JavaScript.

What is stored

We store your GitHub account ID and login, an encrypted access token, session details, scan history, pinned commit references, reports, selected source files needed for fix review, and links to pull requests. The session cookie is required for sign-in. Your language choice stays in your browser.

Retention

Sessions expire after eight hours or on sign-out. Scan results and the bounded source files needed for proposals are retained for seven days. Expired records are removed during service cleanup; they are unavailable after expiration. Daily and monthly usage counters remain to enforce the free allowance. Pull requests and forks created on GitHub remain on GitHub until you remove them there.

Where processing happens

GitHub provides repository content and authentication. On the hosted service, Vercel serves the application and runs disposable scanner environments; a PostgreSQL database stores private application records and results. Cloned repositories are deleted after scanning. Repository code is parsed, never installed, imported, executed or tested.

Your controls

Sign out to remove your current session. You can revoke Quanta's access in GitHub's application settings. For questions or deletion requests, contact the project through GitHub. Never include tokens or sensitive source code in a public issue.

No analytics or advertising

Quanta does not add advertising, analytics trackers or marketing cookies. Hosting providers may retain operational request logs according to their own policies.
