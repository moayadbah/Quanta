Use hybrid key exchange in TLSSites: 6

OpenSSL 3.5 and later offer X25519MLKEM768 by default. Check the linked version rather than changing the code. Replacement: X25519MLKEM768 in TLS 1.3.

import ssl

# OpenSSL 3.5 and later offer X25519MLKEM768 by default in TLS 1.3, so no code
# change is needed once the runtime links it. Fail loudly where it does not.
HYBRID_READY = ssl.OPENSSL_VERSION_INFO >= (3, 5)

context = ssl.create_default_context()
context.minimum_version = ssl.TLSVersion.TLSv1_3
if not HYBRID_READY:
    print("Upgrade the Python runtime to one built with OpenSSL 3.5+:", ssl.OPENSSL_VERSION)
